1. Les acteurs d'un projet

Le commanditaire (sponsor)

  • Finance ou soutient le projet.

  • Valide les grandes décisions.

Le chef de projet

  • Coordonne l'ensemble des activités.

  • Suit l'avancement.

  • Gère les risques et la communication.

L'équipe projet

  • Réalise les tâches opérationnelles.

Les parties prenantes

Toute personne ou organisation impactée par le projet :

  • Clients

  • Fournisseurs

  • Utilisateurs

  • Direction

  • Administrations

2. Le cycle de vie d'un projet

Phase 1 : Initiation

Objectif : définir le projet.

Questions clés :

  • Pourquoi réaliser ce projet ?

  • Quels sont les objectifs ?

  • Qui est concerné ?

Livrables :

  • Note de cadrage

  • Cahier des charges simplifié

Phase 2 : Planification

Objectif : préparer le projet.

Actions :

  • Définir les tâches.

  • Estimer les délais.

  • Évaluer les coûts.

  • Identifier les risques.

Outils :

  • Diagramme de Gantt

  • Planning

  • Budget prévisionnel

Phase 3 : Exécution

Objectif : réaliser le travail prévu.

Activités :

  • Répartition des tâches.

  • Production des livrables.

  • Réunions de suivi.

Phase 4 : Contrôle et suivi

Objectif : vérifier que le projet avance correctement.

Indicateurs :

  • Respect du planning.

  • Respect du budget.

  • Qualité des livrables.

  • Gestion des risques.

Phase 5 : Clôture

Objectif : terminer officiellement le projet.

Actions :

  • Validation des livrables.

  • Bilan du projet.

  • Capitalisation des retours d'expérience.

4. Les risques d'un projet

Un risque est un événement incertain pouvant avoir un impact sur le projet.

Exemples

  • Retard fournisseur.

  • Départ d'un collaborateur.

  • Dépassement budgétaire.

  • Changement des besoins du client.

Gestion des risques

  1. Identifier les risques.

  2. Évaluer leur impact.

  3. Définir des actions préventives.

  4. Mettre en place un suivi.

5. Les méthodes de gestion de projet

Approche classique (cycle en V)

Caractéristiques :

  • Planification détaillée dès le départ.

  • Phases successives.

  • Adaptée aux projets stables.

Exemples :

  • Construction.

  • Industrie.

Approche Agile

Caractéristiques :

  • Travail par itérations courtes.

  • Adaptation rapide aux changements.

  • Collaboration forte avec le client.

Méthodes populaires :

  • Scrum

  • Kanban
