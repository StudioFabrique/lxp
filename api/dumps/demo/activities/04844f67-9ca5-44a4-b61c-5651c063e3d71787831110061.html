Besoin exprimé

Le besoin exprimé est formulé directement.

Exemple :

« J’aimerais une chambre calme. »

Le réceptionniste sait précisément ce que souhaite le client.

Besoin implicite

Le besoin implicite n’est pas directement formulé.

Exemple :

Le client indique :

« Je dois partir demain matin à 5 h. »

Il n’a pas demandé explicitement quelque chose.

Mais cette information peut révéler plusieurs besoins potentiels :

  • un réveil ;

  • un taxi ;

  • un petit déjeuner à emporter ;

  • une procédure de départ anticipé.

Le réceptionniste peut alors demander :

« Souhaitez-vous que nous organisions un taxi ou un petit déjeuner à emporter pour votre départ ? »

Ne pas faire de suppositions

Identifier un besoin implicite ne signifie pas décider à la place du client.

Le réceptionniste peut proposer, mais doit vérifier.

À éviter :

« Puisque vous avez des enfants, vous avez besoin d’un lit bébé. »

Préférable :

« Avez-vous besoin d’un équipement particulier pour les enfants ? »
