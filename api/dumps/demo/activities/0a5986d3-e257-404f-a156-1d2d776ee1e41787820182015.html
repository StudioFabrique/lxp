Un client peut être :

  • fatigué ;

  • stressé ;

  • en retard ;

  • mécontent ;

  • confronté à un problème qui ne dépend pas directement du réceptionniste.

Le réceptionniste doit éviter de répondre sur le même registre émotionnel.

Exemple

Client :

« C’est inadmissible ! J’attends depuis vingt minutes ! »

Réponse inadaptée :

« Ce n’est pas de ma faute, nous sommes débordés ! »

Réponse professionnelle :

« Je comprends que l’attente soit désagréable. Je vais maintenant prendre en charge votre demande. »

Maintenir les limites professionnelles

Être accueillant ne signifie pas accepter tous les comportements.

Le réceptionniste peut être amené à rappeler une règle.

Il doit le faire de manière :

  • calme ;

  • claire ;

  • factuelle ;

  • respectueuse.

Exemple

Client :

« Je veux absolument fumer dans ma chambre. »

Réponse :

« Je comprends votre demande, mais toutes nos chambres sont non-fumeurs. Je peux en revanche vous indiquer l’espace où il est possible de fumer. »

La règle est maintenue tout en proposant une alternative.
