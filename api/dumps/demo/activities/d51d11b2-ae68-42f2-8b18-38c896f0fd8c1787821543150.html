Une procédure permet de transformer une activité complexe en une succession d’étapes simples.

À la réception, plusieurs opérations doivent parfois être réalisées rapidement.

Sans méthode, il est facile d’oublier une étape.

Par exemple :

  • vérifier l’identité ;

  • confirmer le type de chambre ;

  • enregistrer une information ;

  • remettre une clé ;

  • expliquer les horaires.

Une procédure permet donc de sécuriser le travail.

Exemple d’une procédure générale d’accueil

La procédure précise varie selon l’établissement, mais une logique générale peut être utilisée.

Étape 1 — Reconnaître et saluer le client

« Bonjour Madame, bienvenue. »

Le client doit comprendre immédiatement qu’il est pris en charge.

Étape 2 — Identifier la raison de sa présence

« Comment puis-je vous aider ? »

ou :

« Avez-vous une réservation ? »

Étape 3 — Identifier le client

Il peut être nécessaire de demander :

  • son nom ;

  • une référence de réservation ;

  • les dates du séjour ;

  • une pièce d’identité selon la procédure de l’établissement.

Étape 4 — Vérifier les informations

Le réceptionniste consulte le système et contrôle les éléments nécessaires.

Par exemple :

  • dates ;

  • nombre de personnes ;

  • type de chambre ;

  • prestations réservées ;

  • demandes particulières.

Étape 5 — Réaliser les formalités prévues

Selon l’établissement, cela peut inclure :

  • compléter les informations du dossier ;

  • faire signer un document ;

  • vérifier ou enregistrer un moyen de paiement ;

  • attribuer la chambre ;

  • remettre une clé ou une carte.

Étape 6 — Donner les informations essentielles

Par exemple :

  • emplacement de la chambre ;

  • horaires du petit déjeuner ;

  • heure du check-out ;

  • Wi-Fi ;

  • services disponibles ;

  • fonctionnement de la réception.

Étape 7 — Vérifier si le client a une autre demande

« Avez-vous besoin d’une autre information ? »

Étape 8 — Conclure l’accueil

« Je vous souhaite un agréable séjour. »
