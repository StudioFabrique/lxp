Lorsque la satisfaction est vérifiée pendant le séjour, l’établissement peut encore agir.

Après le départ, il est parfois trop tard pour corriger le problème.

Exemple :

« Votre chambre vous convient-elle ? »

« Tout se passe bien depuis votre arrivée ? »

« Avez-vous besoin de quelque chose pour la suite de votre séjour ? »

Choisir le bon moment

Il faut éviter de solliciter constamment le client.

Le retour peut être demandé :

  • après l’installation ;

  • lors d’un passage à la réception ;

  • après le traitement d’une demande ;

  • avant le départ.
