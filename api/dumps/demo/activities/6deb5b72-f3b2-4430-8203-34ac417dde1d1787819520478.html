Lorsque deux personnes communiquent en face à face, le message ne passe pas uniquement par les mots.

La communication comporte notamment :

Une dimension verbale

Ce sont les mots utilisés.

Une dimension vocale

Elle comprend notamment :

  • le ton ;

  • le volume ;

  • le débit ;

  • les pauses.

Une dimension non verbale

Elle comprend notamment :

  • le regard ;

  • les expressions du visage ;

  • les gestes ;

  • la posture ;

  • l’orientation du corps.

Ces éléments fonctionnent ensemble.

La communication verbale

Une bonne communication verbale doit être :

  • claire ;

  • précise ;

  • structurée ;

  • adaptée au client.

Il faut éviter un vocabulaire inutilement technique.

Exemple

Un client demande :

« Pourquoi le tarif est-il plus cher vendredi ? »

Une réponse claire :

« Les tarifs peuvent varier selon la période et le niveau de réservation de l’hôtel. Vendredi, la demande est actuellement plus importante. »

Cette réponse est plus utile qu’une explication utilisant uniquement du jargon professionnel.

Le ton de la voix

Une même phrase peut être perçue différemment selon le ton utilisé.

Par exemple :

« Je vais vérifier votre réservation. »

Cette phrase peut sembler :

  • rassurante ;

  • neutre ;

  • agacée ;

  • impatiente ;

selon la manière dont elle est prononcée.

Un ton professionnel doit généralement rester :

  • calme ;

  • audible ;

  • posé ;

  • respectueux.

Le débit

Parler trop vite peut rendre les informations difficiles à comprendre.

Cela peut être particulièrement problématique :

  • avec une clientèle internationale ;

  • avec une personne âgée ;

  • lorsqu’une information comporte des horaires ou des chiffres ;

  • lorsqu’un client est stressé.

Il est donc important d’adapter son rythme.

Exemple

Pour communiquer une information importante :

« Le petit déjeuner est servi de 7 heures à 10 heures, au rez-de-chaussée, à côté de la réception. »

Le réceptionniste peut ralentir légèrement sur les éléments essentiels.

Le regard

Lors d’un accueil physique, le regard permet de montrer au client qu’il est pris en compte.

Un contact visuel approprié peut signifier :

  • « je vous écoute » ;

  • « j’ai compris que vous êtes là » ;

  • « votre demande m’intéresse ».

Il ne s’agit cependant pas de fixer constamment le client.

Le regard doit rester naturel.

Les expressions du visage

L’expression du visage peut confirmer ou contredire les paroles.

Imaginez qu’un réceptionniste dise :

« Bien sûr Madame, je vais vous aider. »

tout en soupirant et en levant les yeux au ciel.

Les paroles sont correctes, mais le message réellement perçu par le client est négatif.

Il faut donc rechercher une cohérence entre :

ce que l’on dit et ce que l’on montre.

La posture corporelle

Une posture fermée peut donner une impression de distance ou de désintérêt.

Par exemple :

  • rester tourné vers l’écran ;

  • tourner le dos au client ;

  • manifester de l’impatience ;

  • effectuer constamment une autre tâche pendant que le client parle.

À l’inverse, une posture ouverte montre davantage de disponibilité.

Les gestes

Les gestes peuvent faciliter la communication.

Par exemple, pour indiquer :

  • la direction de l’ascenseur ;

  • l’emplacement du restaurant ;

  • le chemin vers une salle.

Ils doivent rester :

  • clairs ;

  • mesurés ;

  • respectueux.

Il est préférable d’accompagner le geste d’une explication.

Exemple

« L’ascenseur se trouve juste à votre gauche après le salon. »

Observer également le client

La communication non verbale fonctionne dans les deux sens.

Le réceptionniste peut observer certains signes qui indiquent qu’un client :

  • ne comprend pas ;

  • hésite ;

  • est pressé ;

  • semble mécontent ;

  • cherche quelque chose ;

  • souhaite poser une question.

Il faut toutefois éviter de tirer des conclusions trop rapidement.

Un comportement observé est un indice, pas une certitude.

Il faut confirmer par la communication.

Exemple

« Est-ce que tout est clair concernant les horaires ? »
