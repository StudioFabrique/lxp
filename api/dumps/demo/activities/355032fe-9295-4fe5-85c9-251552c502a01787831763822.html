Toutes les demandes ne peuvent pas être acceptées.

Il faut vérifier :

  • la disponibilité ;

  • les règles de l’établissement ;

  • le coût éventuel ;

  • les délais ;

  • les contraintes techniques ;

  • la capacité du service concerné.

Il ne faut jamais promettre une prestation avant d’avoir vérifié qu’elle peut être réalisée.

À éviter :

« Oui, aucun problème. »

si la faisabilité n’a pas été contrôlée.

Préférable :

« Je vais vérifier immédiatement si nous pouvons organiser cela. »
