Oublier une information importante

Exemple :

ne pas expliquer l’heure du petit déjeuner.

Conséquence

Le client doit rappeler ou revenir demander l’information.

Ne pas vérifier une information

Exemple :

supposer qu’une chambre est prête sans vérifier son statut.

Conséquence

Le client peut être envoyé vers une chambre indisponible.

Utiliser une procédure mécaniquement

Exemple :

réciter toutes les informations sans tenir compte du client.

Conséquence

Le client peut ne pas retenir les informations importantes.

Ne pas tracer une demande

Exemple :

un client demande un lit bébé, mais la demande n’est pas enregistrée.

Conséquence

l’équipe suivante ignore la demande.

Ne pas assurer le suivi

Exemple :

« Je vais demander au service technique de passer. »

Mais aucune vérification n’est ensuite réalisée.

Conséquence

le client peut considérer que sa demande a été oubliée.
