La réception joue souvent un rôle de coordination.

Une demande peut nécessiter l’intervention :

  • du service des étages ;

  • de la restauration ;

  • de la maintenance ;

  • d’un responsable ;

  • d’un prestataire extérieur.

Une transmission efficace doit préciser :

  • le client concerné ;

  • le numéro de chambre ;

  • la demande ;

  • le délai ;

  • les éventuelles contraintes.

Après la transmission, la réception doit vérifier que l’action a bien été réalisée.
