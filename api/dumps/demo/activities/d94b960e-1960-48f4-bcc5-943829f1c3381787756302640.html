À la fin de cette leçon, l’apprenant doit être capable de :

  • identifier rapidement le type de demande ;

  • poser les questions nécessaires ;

  • fournir une première réponse adaptée ;

  • reconnaître les limites de son champ d’intervention ;

  • transmettre correctement une demande lorsqu’elle nécessite l’intervention d’un autre service.
