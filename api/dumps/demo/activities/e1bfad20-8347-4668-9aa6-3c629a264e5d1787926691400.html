Pendant longtemps, le navigateur a été le seul endroit où le code JavaScript pouvait être exécuté. 

JavaScript a été initialement conçu pour s'exécuter uniquement dans le navigateur. Tous les navigateurs sont équipés de moteurs JavaScript pour exécuter JavaScript. Par exemple, Mozilla Firefox est propulsé par SpiderMonkey, tandis que Chrome utilise le moteur V8.

Les développeurs Web devaient utiliser un langage de programmation différent sur le front-end que sur le back-end. L'arrivé de Nods Js en 2009 nous a permis d'exécuter le code Js en dehors du navigateur... Node Js est:  

Un environnement qui nous permet d'exécuter du code JavaScript en dehors du navigateur.  Un « runtime » convertit le code écrit dans un langage de programmation de haut niveau lisible par l'homme et le compile en code que l'ordinateur peut exécuter.

REPL

- Read - Eval - Print - Loop

Il s'agit d'un programme qui boucle, ou fait des cycles répétés, à travers trois états différents : 

- *READ*: un état de lecture où le programme lit l'entrée d'un utilisateur,

- *EVAL*: l'état d'évaluation où le programme évalue l'entrée de l'utilisateur 

- *PRINT*: l'état d'impression où le programme imprime son évaluation sur une console. Ensuite, il parcourt à nouveau ces états.

Lorsque vous installez Node, il est livré avec un REPL JavaScript intégré. Vous pouvez accéder au REPL en tapant la commande - node -  dans le terminal et en appuyant sur Entrée. Un caractère > apparaîtra dans le terminal, indiquant que le REPL est en cours d'exécution et vous invite à entrer. 

Le Node REPL évaluera votre entrée ligne par ligne. Le REPL peut être extrêmement utile pour effectuer des calculs, apprendre un langage et développer du code. L 'environnement Node contient un certain nombre d'éléments globaux spécifiques à Node en plus de ceux intégrés au langage JavaScript.

```
$ node
```

Puis 

```
> console.log(global)
// ou
> global
```

Test 

```
> global.cat = 'meow!'
// puis
> console.log(global.cat)
'meow!'
```

Si vous êtes familier avec l'exécution de JavaScript sur le navigateur, vous avez probablement rencontré l'objet Window. Voici une des principales différences entre Node : essayez d'accéder à l'objet Window (cela générera une erreur). L'objet Window est l'objet JavaScript dans le navigateur qui contient le DOM, puisque nous n'avons pas de DOM ici, il n'y a pas d'objet Window.
