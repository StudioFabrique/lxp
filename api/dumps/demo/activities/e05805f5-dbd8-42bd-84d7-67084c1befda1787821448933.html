Un client arrive et annonce :

« Bonjour, j’ai une réservation au nom de Laurent Dubois. »

Le réceptionniste retrouve une réservation au nom de « Dubois », mais la date d’arrivée indiquée est le lendemain.

Réaction inadaptée

« Votre réservation est pour demain. Vous vous êtes trompé. »

Réaction professionnelle

« Je retrouve bien une réservation à votre nom, mais elle apparaît actuellement avec une arrivée prévue demain. Nous allons vérifier ensemble votre confirmation afin de comprendre la situation. »

La procédure est alors :

  1. identifier le client ;

  2. consulter la réservation ;

  3. constater la différence ;

  4. vérifier les documents ;

  5. rechercher une solution selon les règles de l’établissement.
