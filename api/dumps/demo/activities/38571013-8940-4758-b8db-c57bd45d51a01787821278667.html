Les deux notions sont proches, mais elles ne désignent pas exactement la même chose.

Standard

Le standard indique le niveau de service attendu.

Exemple :

Toute personne entrant dans l’établissement doit être reconnue et saluée rapidement.

Procédure

La procédure indique comment réaliser une opération.

Exemple :

  1. saluer le client ;

  2. demander son nom ;

  3. retrouver la réservation ;

  4. vérifier les informations ;

  5. effectuer les formalités nécessaires ;

  6. remettre la clé ;

  7. donner les informations pratiques.

Le standard définit donc davantage ce qui est attendu, alors que la procédure décrit comment le réaliser.

Standardisation ne signifie pas comportement robotique

Appliquer un standard ne signifie pas réciter exactement la même phrase à chaque client.

Par exemple, le standard peut être :

Saluer le client dès son arrivée.

Plusieurs formulations peuvent être acceptables :

« Bonjour Madame, bienvenue. »

« Bonjour Monsieur, bienvenue dans notre établissement. »

« Bonjour, bienvenue parmi nous. »

L’objectif reste le même.

Le réceptionniste doit respecter le standard tout en conservant une communication naturelle.
