Lors d’un accueil physique, une grande partie de la communication passe par le comportement.

Le réceptionniste doit notamment :

  • regarder le client ;

  • saluer rapidement ;

  • adopter une attitude ouverte ;

  • montrer qu’il a identifié sa présence ;

  • écouter sans effectuer simultanément une autre tâche lorsque cela peut être évité.

Même lorsqu’il est déjà occupé, il peut reconnaître la présence du nouveau client.

Exemple :

« Bonjour Madame, je m’occupe de vous dans un instant. »

Cette phrase évite que la personne ait l’impression d’être ignorée.

À éviter

  • poursuivre une conversation personnelle devant le client ;

  • regarder constamment son écran sans reconnaître sa présence ;

  • parler avec un collègue pendant que le client attend ;

  • utiliser un vocabulaire familier inapproprié ;

  • montrer son agacement.
