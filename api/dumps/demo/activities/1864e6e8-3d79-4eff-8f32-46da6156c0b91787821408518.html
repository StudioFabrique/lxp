Dans certaines situations, une checklist peut être utile.

Exemple simplifié :

  • réservation retrouvée ;

  • identité vérifiée ;

  • dates confirmées ;

  • type de chambre confirmé ;

  • demandes particulières vérifiées ;

  • moyen de paiement traité selon la procédure ;

  • clé remise ;

  • informations essentielles données.

La checklist est particulièrement utile pour :

  • les nouveaux employés ;

  • les périodes de forte activité ;

  • les opérations comportant de nombreuses étapes.
