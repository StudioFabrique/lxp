L’accueil digital peut avoir lieu notamment par :

  • e-mail ;

  • messagerie ;

  • formulaire du site internet ;

  • plateforme de réservation ;

  • outil de communication numérique utilisé par l’établissement.

Une réponse professionnelle doit généralement contenir :

  1. une salutation ;

  2. une prise en compte de la demande ;

  3. une réponse claire ;

  4. les informations pratiques nécessaires ;

  5. une formule de conclusion.

Exemple

« Bonjour Madame Martin,

Merci pour votre message.

Nous vous confirmons qu’un lit bébé peut être installé dans votre chambre sans supplément. Nous pouvons le préparer avant votre arrivée si vous le souhaitez.

N’hésitez pas à nous contacter pour toute autre demande.

Cordialement,
La réception »
