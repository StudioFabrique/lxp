Certaines situations nécessitent une adaptation.

Par exemple, le standard prévoit une présentation complète des services lors du check-in.

Mais un client arrive très en retard et explique qu’il souhaite aller immédiatement dans sa chambre.

Le réceptionniste peut donner uniquement les informations indispensables :

« Le petit déjeuner est servi de 7 h à 10 h. Le Wi-Fi est indiqué sur votre carte. Si vous avez besoin de quoi que ce soit, composez le 9 depuis votre chambre. »

Le reste pourra être expliqué plus tard.

Le standard n’est donc pas nécessairement une suite rigide de phrases.

Il constitue un cadre.

Respecter les standards protège aussi le réceptionniste

Les procédures permettent au salarié de savoir :

  • ce qu’il doit faire ;

  • dans quel ordre ;

  • quelles informations vérifier ;

  • quand demander l’aide d’un responsable ;

  • quelles actions sont autorisées.

Elles diminuent le risque de décisions improvisées.
