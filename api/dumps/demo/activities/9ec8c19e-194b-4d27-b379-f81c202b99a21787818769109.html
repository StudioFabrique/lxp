Certaines phrases peuvent être grammaticalement correctes mais donner une mauvaise impression au client.

Exemple 1

À éviter :

« Je ne sais pas. »

Préférable :

« Je vais vérifier cette information pour vous. »

Exemple 2

À éviter :

« Ce n’est pas mon problème. »

Préférable :

« Cette demande concerne un autre service. Je vais vous indiquer qui peut vous aider. »

Exemple 3

À éviter :

« Vous devez attendre. »

Préférable :

« Je vais avoir besoin de quelques instants pour effectuer cette vérification. »

Exemple 4

À éviter :

« Vous vous êtes trompé. »

Préférable :

« Je vais vérifier avec vous les informations de la réservation. »

La différence repose sur la manière de présenter la situation.

Éviter un langage trop familier

La réception est un environnement professionnel.

Certaines expressions utilisées entre amis ou collègues peuvent être inadaptées avec un client.

Par exemple :

  • « Pas de souci » peut être remplacé par « Bien sûr » ou « Avec plaisir » ;

  • « Salut » par « Bonjour » ;

  • « Attendez » par « Je vous remercie de patienter quelques instants ».

Le niveau de formalité peut néanmoins varier selon :

  • le type d’établissement ;

  • le profil de clientèle ;

  • la culture de l’entreprise ;

  • la situation.

L’objectif est de rester naturel tout en maintenant une communication professionnelle.
