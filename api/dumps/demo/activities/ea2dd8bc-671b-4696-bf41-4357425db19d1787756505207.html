Il existe deux grands types de questions.

Les questions ouvertes

Elles permettent au client d’expliquer sa demande.

Exemples :

  • « Comment puis-je vous aider ? »

  • « Que recherchez-vous exactement ? »

  • « Que puis-je faire pour vous ? »

Les questions fermées

Elles permettent de confirmer une information précise.

Exemples :

  • « Votre réservation est-elle pour ce soir ? »

  • « Souhaitez-vous une chambre double ? »

  • « Êtes-vous déjà client de l’établissement ? »

Les deux types de questions sont complémentaires.

Une bonne pratique consiste souvent à :

commencer par une question ouverte, puis utiliser des questions plus précises pour clarifier la demande.

Reformuler avant d’agir

Une mauvaise compréhension peut entraîner :

  • une erreur de réservation ;

  • une mauvaise information ;

  • une insatisfaction ;

  • une perte de temps ;

  • une mauvaise coordination avec les autres services.

La reformulation permet donc de sécuriser la demande.

Exemple :

« Si j’ai bien compris, vous souhaitez modifier votre réservation du 12 au 14 mai pour arriver finalement le 13 mai, c’est bien cela ? »

Répondre lorsque l’information est disponible

Lorsque le réceptionniste connaît la réponse, celle-ci doit être :

  • précise ;

  • simple ;

  • complète ;

  • compréhensible.

Client :

« À quelle heure devons-nous libérer la chambre ? »

Réponse :

« Le check-out est prévu avant 11 h. »

Une réponse utile peut éventuellement être complétée :

« Si vous avez besoin de conserver vos bagages après votre départ, nous pouvons les garder à la réception. »

Que faire lorsqu’on ne connaît pas la réponse ?

Un réceptionniste ne peut pas connaître toutes les informations.

Il ne faut pas inventer une réponse.

Une attitude professionnelle consiste à :

  1. reconnaître que l’information doit être vérifiée ;

  2. expliquer ce que l’on va faire ;

  3. rechercher l’information ;

  4. revenir vers le client.

Exemple :

« Je vais vérifier cette information auprès du service concerné. »

Cette réponse est préférable à une réponse approximative.

Transmettre une demande

Certaines demandes relèvent d’un autre service.

Par exemple :

  • problème technique → maintenance ;

  • demande liée au ménage → service des étages ;

  • réservation de restaurant → restauration ;

  • demande commerciale spécifique → responsable concerné.

La réception joue alors un rôle de coordination.

Une bonne transmission doit préciser :

  • qui est le client ;

  • quelle est sa demande ;

  • où il se trouve ;

  • le degré d’urgence ;

  • les actions déjà réalisées.

7. Gérer plusieurs clients simultanément

La réception peut connaître des périodes de forte activité.

Le réceptionniste doit alors prioriser sans ignorer les personnes qui attendent.

Par exemple :

Un réceptionniste est au téléphone lorsqu’un client arrive.

Il peut :

  • établir un contact visuel ;

  • faire un signe indiquant qu’il a vu le client ;

  • terminer efficacement l’appel ;

  • accueillir ensuite le client.

L’objectif est que chaque personne sache que sa présence ou sa demande a été prise en compte.
