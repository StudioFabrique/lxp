Lorsqu’une insatisfaction est identifiée, le réceptionniste doit :

  1. écouter ;

  2. comprendre précisément le problème ;

  3. vérifier les faits si nécessaire ;

  4. proposer une solution dans son champ d’action ;

  5. transmettre lorsque nécessaire ;

  6. vérifier ensuite si la situation est résolue.

Exemple

Client :

« Le Wi-Fi fonctionne très mal dans ma chambre. »

Réponse professionnelle :

« Je comprends. Je vais vérifier si le problème est déjà identifié et voir immédiatement quelle solution nous pouvons vous proposer. »

Le suivi est essentiel.

Une fois l’intervention réalisée :

« Est-ce que la connexion fonctionne correctement maintenant ? »
