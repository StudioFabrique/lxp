Un client satisfait peut :

  • remercier le personnel ;

  • revenir dans l’établissement ;

  • utiliser les services proposés ;

  • formuler des commentaires positifs.

Un client insatisfait peut :

  • se plaindre ;

  • poser plusieurs fois la même question ;

  • manifester de l’agacement ;

  • réduire ses interactions ;

  • signaler plusieurs petits problèmes.

Ces éléments constituent des indicateurs, mais ils doivent être interprétés avec prudence.
