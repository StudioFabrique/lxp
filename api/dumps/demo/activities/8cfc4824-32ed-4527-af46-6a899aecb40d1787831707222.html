Traiter une réclamation ne signifie pas uniquement proposer une solution.

Il faut également vérifier son efficacité.

Par exemple :

« La nouvelle chambre vous convient-elle mieux ? »

Le suivi montre au client que sa réclamation a réellement été prise en compte.

Il permet également de détecter rapidement si le problème persiste.

À éviter lors d’une réclamation

  • accuser un collègue ;

  • contredire immédiatement le client ;

  • minimiser son problème ;

  • faire une promesse impossible à tenir ;

  • oublier d’assurer le suivi ;

  • montrer de l’agacement.
