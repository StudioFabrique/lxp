Certaines attitudes peuvent détériorer rapidement l’image de l’établissement.

Il faut notamment éviter :

  • les conversations personnelles prolongées ;

  • l’utilisation personnelle du téléphone devant les clients ;

  • les critiques concernant un collègue ;

  • les critiques concernant l’établissement ;

  • les disputes entre membres du personnel ;

  • les commentaires sur d’autres clients ;

  • les manifestations visibles d’agacement.

Même si le problème ne concerne pas directement le client, celui-ci observe le fonctionnement de l’établissement.

La discrétion professionnelle

Le réceptionniste peut avoir accès à des informations concernant :

  • l’identité des clients ;

  • leur numéro de chambre ;

  • leurs coordonnées ;

  • leurs habitudes ;

  • leurs réservations ;

  • leurs paiements ;

  • leurs demandes particulières.

Ces informations ne doivent pas être communiquées sans raison légitime.

Exemple

Une personne demande :

« Est-ce que Monsieur Martin séjourne actuellement dans votre hôtel ? »

Le réceptionniste ne doit pas automatiquement confirmer la présence du client.

La discrétion fait partie de la posture professionnelle.
