Une fois la réclamation entendue, il faut :

  1. reformuler ;

  2. identifier précisément le problème ;

  3. vérifier les possibilités ;

  4. proposer une solution réaliste.

Exemple

« Si je comprends bien, le bruit provient principalement de la rue depuis votre arrivée. Je vais vérifier si nous avons une chambre disponible sur une autre partie de l’établissement. »

La solution dépend :

  • de la gravité ;

  • des possibilités de l’établissement ;

  • des procédures ;

  • du niveau d’autorité du réceptionniste.
