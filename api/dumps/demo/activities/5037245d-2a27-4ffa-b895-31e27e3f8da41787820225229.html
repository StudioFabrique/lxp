Le principe de professionnalisme reste constant.

En revanche, la manière de communiquer doit s’adapter.

Le réceptionniste ne communique pas exactement de la même manière avec :

  • un client pressé ;

  • une famille avec enfants ;

  • un groupe ;

  • un client international ;

  • un client qui ne comprend pas une information ;

  • un client mécontent ;

  • un client en situation de handicap ;

  • un client qui a besoin d’aide ;

  • un client habitué de l’établissement.

S’adapter ne signifie pas modifier les règles de l’établissement.

Cela signifie adapter la manière de prendre en charge la personne.

Face à un client pressé

Un client pressé recherche généralement :

  • une réponse rapide ;

  • des informations essentielles ;

  • peu d’attente.

Le réceptionniste peut raccourcir ses explications.

Exemple

Client :

« Je suis désolé, mon taxi m’attend. Je dois régler rapidement. »

Réceptionniste :

« Bien sûr. Votre facture est prête. Le montant est de 148 euros. Souhaitez-vous régler avec la même carte que lors de votre arrivée ? »

L’objectif est d’aller directement à l’essentiel.

Face à un client qui ne comprend pas

Si le client ne comprend pas une information, répéter exactement la même phrase plus fort n’est généralement pas une solution.

Il est préférable de :

  1. ralentir ;

  2. simplifier ;

  3. reformuler ;

  4. montrer lorsque cela est possible ;

  5. vérifier la compréhension.

Exemple

Première formulation :

« Vous devez utiliser votre carte magnétique pour accéder à l’espace après 22 heures. »

Reformulation :

« Après 22 heures, la porte est fermée. Utilisez votre carte de chambre ici pour entrer. »

Face à une clientèle internationale

La barrière linguistique peut nécessiter une adaptation.

Il peut être utile de :

  • parler lentement ;

  • utiliser des phrases courtes ;

  • éviter les expressions complexes ;

  • écrire les informations importantes ;

  • montrer un plan ou un document ;

  • vérifier la compréhension.

Il ne faut pas considérer automatiquement qu’une difficulté linguistique signifie que le client ne comprend rien.

Le réceptionniste doit rester respectueux et patient.

Face à un client mécontent

La posture professionnelle devient particulièrement importante lorsqu’un client exprime une insatisfaction.

La première réaction ne doit pas être de chercher immédiatement à prouver que l’établissement a raison.

Il faut d’abord comprendre le problème.

Une démarche simple consiste à :

1. Écouter

Laisser le client expliquer la situation.

2. Reformuler

« Si je comprends bien, vous aviez demandé une chambre calme et votre chambre donne actuellement sur la rue. »

3. Reconnaître la situation

« Je comprends que cette situation soit gênante. »

4. Chercher une solution

« Je vais vérifier immédiatement si nous pouvons vous proposer une autre chambre. »

Cette démarche ne signifie pas que toutes les demandes doivent être acceptées.

Elle permet d’éviter l’escalade.

Face à plusieurs clients

Pendant une période de forte activité, la posture professionnelle consiste également à gérer l’attente.

Il faut éviter d’ignorer les personnes présentes.

Exemple

Trois clients attendent pendant que le réceptionniste termine une opération.

Il peut dire :

« Bonjour Mesdames, Messieurs. Merci de patienter quelques instants, je vais m’occuper de vous dans l’ordre d’arrivée. »

Cette courte intervention permet de reconnaître les personnes présentes.

Face à une erreur de l’établissement

Une erreur peut arriver :

  • mauvaise chambre attribuée ;

  • demande oubliée ;

  • réservation mal enregistrée ;

  • information incorrecte.

Une posture professionnelle consiste à éviter de chercher immédiatement un responsable à blâmer devant le client.

À éviter :

« C’est mon collègue qui s’est trompé hier. »

Préférable :

« Je vais vérifier ce qui s’est passé et voir comment nous pouvons corriger la situation. »

Pour le client, le réceptionniste représente l’établissement.

Face à une erreur du client

Le client peut également s’être trompé.

Il faut éviter une formulation accusatrice.

Exemple

Le client affirme avoir réservé pour le 15 juin, mais la réservation enregistrée indique le 15 juillet.

À éviter :

« Vous vous êtes trompé de date. »

Préférable :

« La réservation que je retrouve dans notre système est actuellement enregistrée pour le 15 juillet. Regardons ensemble votre confirmation afin de vérifier les dates. »

Cette formulation permet de traiter le problème sans confrontation inutile.
