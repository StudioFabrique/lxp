À la fin de cette leçon, l’apprenant doit être capable de :

  • expliquer le rôle de l’accueil dans l’expérience client ;

  • identifier les différentes étapes d’un accueil professionnel ;

  • adopter une communication claire, courtoise et adaptée ;

  • identifier les informations essentielles à recueillir lors d’un premier contact.
