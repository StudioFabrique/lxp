Une procédure peut être réalisée sans erreur technique tout en produisant une mauvaise expérience client.

Par exemple, le réceptionniste peut :

  • retrouver la réservation ;

  • donner la clé ;

  • expliquer les horaires ;

mais réaliser toutes ces opérations rapidement, sans regarder le client et avec un ton désagréable.

Techniquement, les étapes ont été effectuées.

Mais la qualité de l’accueil reste mauvaise.

Le contrôle doit donc porter sur deux dimensions :

Qualité opérationnelle

Les bonnes actions ont-elles été réalisées ?

Qualité relationnelle

Le client a-t-il été correctement pris en charge ?
