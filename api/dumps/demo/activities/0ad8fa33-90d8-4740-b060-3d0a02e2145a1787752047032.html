Lors d’un premier contact, certaines informations peuvent être nécessaires selon la situation :

  • identité du client ;

  • existence ou non d’une réservation ;

  • dates du séjour ;

  • nombre de personnes ;

  • type de chambre recherché ;

  • demande particulière ;

  • coordonnées du client ;

  • motif de la demande.

Toutes ces informations ne doivent cependant pas être demandées systématiquement.

Le principe est simple :

Recueillir les informations nécessaires pour comprendre et traiter la demande.
