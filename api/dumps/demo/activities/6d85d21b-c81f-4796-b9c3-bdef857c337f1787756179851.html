Un client peut contacter l’établissement :

En face à face

Le réceptionniste utilise :

  • ses paroles ;

  • son ton ;

  • son regard ;

  • ses gestes ;

  • son attitude générale.

Par téléphone

Le client ne voit pas le réceptionniste.

L’accueil repose principalement sur :

  • la voix ;

  • le vocabulaire ;

  • le rythme ;

  • l’écoute ;

  • la précision des informations.

Par écrit ou via un canal digital

Le client ne voit pas et n’entend pas le réceptionniste.

Il juge alors essentiellement :

  • la rapidité de réponse ;

  • la qualité de la rédaction ;

  • la clarté ;

  • la précision ;

  • le ton utilisé.

La règle fondamentale est donc :

Le niveau de professionnalisme doit rester le même, mais la manière de communiquer doit être adaptée au canal.
