L’accueil constitue souvent le premier contact direct entre le client et l’établissement.

Ce premier contact peut avoir lieu :

  • à la réception ;

  • par téléphone ;

  • par e-mail ;

  • via un formulaire de contact ;

  • via une plateforme de réservation ;

  • via une messagerie ou un autre canal numérique.

Le client commence à se faire une opinion de l’établissement dès cette première interaction.

Un accueil de qualité doit lui permettre de ressentir rapidement qu’il est :

  • attendu ;

  • écouté ;

  • compris ;

  • respecté ;

  • pris en charge.

L’objectif n’est donc pas uniquement d’être poli. Il s’agit également de comprendre la demande du client et de lui apporter une réponse appropriée.
