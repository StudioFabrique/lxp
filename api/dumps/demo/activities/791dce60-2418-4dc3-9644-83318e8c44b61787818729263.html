La posture professionnelle

La posture professionnelle correspond à la manière dont une personne se comporte dans le cadre de son activité.

Elle repose sur plusieurs éléments :

  • l’apparence ;

  • la manière de parler ;

  • la manière d’écouter ;

  • le comportement face au client ;

  • la manière de réagir aux difficultés ;

  • le respect des règles de l’établissement ;

  • le comportement avec les collègues.

Être professionnel ne signifie pas être froid ou distant.

Au contraire, le réceptionniste doit trouver un équilibre entre :

courtoisie, disponibilité, efficacité et maîtrise de soi.

La présentation professionnelle

La présentation du réceptionniste participe à la première impression donnée au client.

Elle doit être cohérente avec les standards de l’établissement.

Selon l’établissement, cela peut notamment concerner :

  • la tenue professionnelle ;

  • le port d’un uniforme ;

  • le badge nominatif ;

  • la propreté de la tenue ;

  • la présentation générale ;

  • le respect des règles internes.

L’objectif n’est pas d’imposer un style personnel particulier, mais de garantir une présentation compatible avec l’image professionnelle de l’établissement.

L’attitude au poste de réception

Le comportement du réceptionniste doit montrer qu’il est disponible et attentif.

Une attitude professionnelle peut se traduire par :

  • se tenir correctement ;

  • regarder le client lorsqu’il s’adresse à lui ;

  • saluer le client ;

  • écouter sans manifester d’impatience ;

  • éviter les gestes pouvant être interprétés comme du désintérêt ;

  • rester calme ;

  • garder son espace de travail organisé.

Exemple

Un client entre dans l’établissement alors que le réceptionniste travaille sur son ordinateur.

Une attitude adaptée consiste à interrompre brièvement son activité ou, au minimum, à reconnaître immédiatement la présence du client :

« Bonjour Monsieur, bienvenue. Je suis à vous dans un instant. »

Le client sait ainsi qu’il a été vu et qu’il sera pris en charge.

Le langage professionnel

Le réceptionniste doit utiliser un langage :

  • clair ;

  • poli ;

  • compréhensible ;

  • adapté à la situation ;

  • respectueux.

Dans la plupart des situations professionnelles, le vouvoiement constitue la forme appropriée.

Formulations adaptées

« Bonjour Madame. »

« Comment puis-je vous aider ? »

« Je vais vérifier cette information pour vous. »

« Je vous remercie de patienter quelques instants. »

« Je comprends votre demande. »

« Je vais voir ce que nous pouvons vous proposer. »
