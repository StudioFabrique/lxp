Certains signes peuvent indiquer qu’un problème subsiste.

Par exemple, le client :

  • repose plusieurs fois la même question ;

  • semble hésitant ;

  • regarde autour de lui sans savoir où aller ;

  • manifeste de l’agacement ;

  • revient immédiatement à la réception ;

  • indique qu’une information ne lui a pas été donnée.

Ces éléments doivent inciter le réceptionniste à vérifier la situation.
