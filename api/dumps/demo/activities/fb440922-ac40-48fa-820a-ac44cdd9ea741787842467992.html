Dans la méthode de la cascade, le projet est divisé en étapes possédant chacune ses propres objectifs et livrables. Chaque étape doit être achevée avant de passer à la suivante. C'est comme une cascade, où il faut passer par toutes les étapes dans un ordre linéaire. Les phases sont généralement les suivantes :

  •  Analyse / Exigences
  •  Conception
  •  Réalisation
  •  Test
  •  Livraison / Déploiement

Avantages

  •  Simplicité de mise en œuvre : il suffit de suivre les différentes étapes de la méthode. Les parties prenantes peuvent ainsi aisément suivre l'avancement des travaux.
  •  Structure méthodologique claire, les clients savent ce qu'ils obtiennent
  •  Facilité de gestion et de contrôle : comme tout est planifié, il est facile de voir quelle phase est en cours, ce qui doit être fait, etc.
  •  Contrôle des couts : on sait exactement ce qui sera fait à chaque étape du développement

Inconvénients

  •  Pas flexible pour faire face aux imprévus. Il est compliqué de faire marche arrière pour s'adapter à un nouveau contexte. Le client ne peut pas amender sa demande en cours de projet.
  •  Pas adapté aux projets mal ficelés ou avec comportant une grande part d'incertitudes
  •  Risque de mauvaise évaluation : comme tout est défini en amont, un raté dans le cahier des charges et c'est le processus entier qui peut en pâtir.
  • Les tests sont réalisés à la fin, avec un risque qu'il soit trop tard...

Application 

Pour les projets dont les choix initiaux ne peuvent être changés comme les fabrications et constructions lourdes. La méthode peut être appliquée pour des ouvrages "standards" maîtrisés avec la même structure et les mêmes principes.
