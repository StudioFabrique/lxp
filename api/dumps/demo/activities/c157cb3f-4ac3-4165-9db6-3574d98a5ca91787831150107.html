Deux clients peuvent formuler la même demande mais avoir des attentes différentes.

Par exemple :

« Que pouvons-nous visiter aujourd’hui ? »

Pour une famille avec de jeunes enfants, une activité adaptée peut être différente de celle proposée à un couple souhaitant découvrir le patrimoine culturel.

La personnalisation consiste donc à adapter la proposition au contexte.

Les informations utiles

Pour personnaliser correctement, le réceptionniste peut prendre en compte :

  • la durée du séjour ;

  • le motif du séjour ;

  • la composition du groupe ;

  • les préférences exprimées ;

  • les contraintes de temps ;

  • les besoins particuliers.
