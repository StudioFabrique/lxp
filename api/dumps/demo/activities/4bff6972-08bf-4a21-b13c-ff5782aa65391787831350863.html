Une demande particulière sort du traitement habituel.

Elle peut concerner par exemple :

  • un départ très tôt ;

  • un équipement spécifique ;

  • une alimentation particulière ;

  • une chambre adaptée ;

  • une surprise pour un anniversaire ;

  • un besoin lié à un déplacement professionnel.

Le réceptionniste doit d’abord comprendre exactement la demande.

Exemple

Client :

« Nous souhaitons quelque chose de spécial dans la chambre pour l’anniversaire de ma femme. »

Le réceptionniste doit préciser :

« Bien sûr. Avez-vous déjà une idée de ce que vous souhaitez ou voulez-vous que je vous présente les possibilités proposées par l’établissement ? »
