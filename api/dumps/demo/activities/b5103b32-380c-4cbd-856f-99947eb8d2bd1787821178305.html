Un standard est une référence commune définie par l’établissement pour garantir un niveau de service attendu.

Il peut préciser, par exemple :

  • la manière de saluer un client ;

  • le délai attendu pour prendre en charge une personne ;

  • la formule utilisée au téléphone ;

  • la tenue professionnelle ;

  • les informations à transmettre lors de l’arrivée ;

  • la manière de traiter certaines demandes ;

  • les étapes d’un check-in ;

  • les règles concernant les appels ou les messages.

Les standards peuvent être formalisés dans :

  • un manuel interne ;

  • des fiches de procédures ;

  • un livret d’accueil du personnel ;

  • des documents de formation ;

  • des outils numériques ;

  • des consignes transmises par le responsable.

Pourquoi les standards sont-ils nécessaires ?

Imaginez un établissement où chaque réceptionniste accueille les clients selon ses propres habitudes.

Un réceptionniste donne toutes les informations lors du check-in.

Un autre oublie de parler du petit déjeuner.

Un troisième n’explique pas le fonctionnement du Wi-Fi.

Le client ne reçoit alors pas le même niveau de service selon la personne présente.

Les standards permettent de limiter ce problème.

Ils garantissent une certaine cohérence.

Exemple

Un établissement peut décider que chaque client reçoit systématiquement à son arrivée :

  1. les horaires du petit déjeuner ;

  2. l’heure du check-out ;

  3. les informations concernant le Wi-Fi ;

  4. l’emplacement de l’ascenseur ;

  5. les coordonnées de la réception.

Ainsi, même si le style de communication varie légèrement selon le réceptionniste, les informations essentielles restent les mêmes.

Les standards ne concernent pas uniquement la parole

Un standard peut concerner plusieurs dimensions du service.

Présentation

Par exemple :

  • tenue ;

  • badge ;

  • présentation générale.

Communication

Par exemple :

  • manière de saluer ;

  • formules professionnelles ;

  • façon de répondre au téléphone.

Organisation

Par exemple :

  • vérification des arrivées ;

  • préparation des documents ;

  • mise à jour du dossier client.

Qualité de service

Par exemple :

  • délai de prise en charge ;

  • suivi d’une demande ;

  • transmission d’une information.
