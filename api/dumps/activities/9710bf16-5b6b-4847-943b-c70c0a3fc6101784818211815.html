Lors du développement ou du débogage d'une application, il peut être utile d'avoir des informations sur l'ordinateur, le système d'exploitation et le réseau sur lequel le programme s'exécute. Avant Node, ces informations ne pouvaient pas être récupérées à l'aide de JavaScript car le langage était confiné au navigateur. Cependant, Node.js est un runtime JavaScript, ce qui signifie qu'il peut exécuter du code en dehors du navigateur, et nous pouvons accéder à une grande partie de ces informations via le module os core.
