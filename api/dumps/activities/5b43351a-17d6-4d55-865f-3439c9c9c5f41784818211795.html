Le process.memoryUsage() : il renvoie des informations sur les demandes de processeur du processus en cours.
---

Le process.argv : il contient un tableau de valeurs de ligne de commande fournies lorsque le processus en cours a été lancé. 

  • Le premier élément du tableau est le chemin absolu vers Node, qui a exécuté le processus. 
  • Le deuxième élément du tableau est le chemin d'accès au fichier en cours d'exécution. 
  • Les éléments suivants seront tous les arguments de ligne de commande fournis lorsque le processus a été lancé.

Le process.argv est un objet qui stocke et contrôle les informations sur l'environnement dans lequel le processus est en cours d'exécution. Par exemple, l'objet process.env contient une propriété PWD qui contient une chaîne avec le répertoire dans lequel se trouve le processus actuel.
