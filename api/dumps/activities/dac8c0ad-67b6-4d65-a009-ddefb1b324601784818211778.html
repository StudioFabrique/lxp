La modularité est une technique de conception de logiciels dans laquelle un programme comporte des parties distinctes, chacune fournissant un seul élément de la fonctionnalité globale

Ces modules distincts s'unissent pour former un tout cohérent.  La modularité est importante pour créer des programmes évolutifs qui intègrent des bibliothèques et des cadres et séparent le programme en morceaux gérables. 

Essentiellement, un module est une collection de code située dans un fichier. Au lieu d'avoir un programme entier situé dans un seul fichier, le code est organisé en fichiers séparés en fonction des problèmes auxquels ils répondent. 

Ces fichiers peuvent ensuite être inclus dans d'autres fichiers en utilisant la fonction require(). Le module EVENTS est un module de base de Node.js qui fournit des fonctions clés pour travailler avec, eh bien… des événements
