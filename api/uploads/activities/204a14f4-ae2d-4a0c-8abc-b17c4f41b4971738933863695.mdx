## 2. **Types de tests utilisateurs**

Il existe plusieurs types de tests utilisateurs, chacun ayant des objectifs différents.

#### a. **Tests modérés vs tests non modérés**

* **Tests modérés** : Un facilitateur (ou testeur) guide les utilisateurs pendant le test, leur pose des questions et observe leurs comportements en temps réel. C'est un test plus interactif et flexible. Il peut être réalisé en personne ou à distance.
* **Tests non modérés** : L'utilisateur effectue le test de manière autonome, généralement via un outil en ligne. Le test est enregistré et analysé ensuite. Ce type de test permet de collecter des données à grande échelle et est plus économique.

#### b. **Tests en laboratoire vs tests à distance**

* **Tests en laboratoire** : Réalisés dans un environnement contrôlé, ces tests permettent une observation directe et une interaction étroite avec les utilisateurs. Ils sont utiles pour observer les réactions non verbales et obtenir un feedback détaillé.
* **Tests à distance** : Les utilisateurs effectuent les tests chez eux ou dans un environnement familier, ce qui leur permet d'être plus à l'aise. Cela peut être effectué à distance via des outils comme **Lookback.io** ou **UserTesting**.

#### c. **Tests de performance vs tests qualitatifs**

* **Tests de performance** : Ces tests mesurent la rapidité, l'efficacité et les actions des utilisateurs (par exemple, combien de temps il leur faut pour accomplir une tâche). Ils sont plus orientés vers des résultats quantitatifs.
* **Tests qualitatifs** : Ces tests cherchent à comprendre les attitudes, perceptions et sentiments des utilisateurs. Ils permettent d'obtenir des informations riches sur l'expérience globale, mais ne fournissent pas de mesures exactes.
