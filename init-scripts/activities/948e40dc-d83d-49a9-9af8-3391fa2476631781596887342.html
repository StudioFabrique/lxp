• Contenu théorique (Les concepts clés) : Le HTML5 (HyperText Markup Language) est un langage de balisage qui utilise des balises ouvrantes et fermantes pour structurer le contenu d'une page. La sémantique HTML5 permet de donner du sens au code pour les navigateurs et les moteurs de recherche.

    La structure minimale requise pour tout fichier HTML :

    HTML

    <!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mon Titre</title>
</head>
<body>
    </body>
</html>

    Les balises de structure sémantiques indispensables :

    • <header> : En-tête (titre du site, logo).

    • <nav> : Zone de menu de navigation.

    • <main> : Contenu principal unique de la page.

    • <section> : Regroupement thématique de contenu.

    • <footer> : Pied de page (copyright, mentions légales).

  • Exercice pratique : Ouvrez votre éditeur de code (VS Code) et créez un fichier nommé index.html. Vous devez construire l'architecture complète d'un CV professionnel sans aucun style visuel pour le moment.

    Consignes précises :

    1. Créez l'ossature HTML minimale.

    2. Placez un <header> contenant votre prénom et nom.

    3. Créez un <main> divisé en deux balises <section> distinctes : une pour vos "Expériences" et une pour vos "Formations".

    4. Ajoutez un <footer> contenant vos informations de contact basiques.

  • Livrable attendu : Un fichier index.html valide au validateur W3C, affichant une structure brute et hiérarchisée dans le navigateur.
