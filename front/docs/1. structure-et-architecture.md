# 1. Structure et architecture

## L'arborescence globale du projet

```bash
src/
├── assets/            # Images, polices, fichiers statiques
├── components/        # Uniquement l'UI générique (Boutons, Modales, Inputs...)
│   └── layouts/       # Les "coquilles" visuelles (ex: DashboardLayout.tsx)
├── config/            # Variables d'environnement, constantes, thèmes
├── features/          # Les modules métiers (voir ci-dessous)
├── lib/               # Configuration des librairies tierces (Axios, TanStack Query, Toast)
├── index.router.tsx   # Le routeur principal qui assemble l'application
├── store/             # État global strict (Zustand, Redux, ou vos ContextProviders)
├── utils/             # Fonctions pures uniquement (formateurs, regex, sans effets de bord)
├── App.tsx            # Fichier ultra-léger : ne contient que les Providers globaux
└── main.tsx           # Point de montage React (createRoot)
```

## La structure interne d'une Feature

```bash
features/parcours/
├── api/               # Hooks TanStack Query (ex: useGetParcours.ts, useCreateModule.ts)
├── assets/            # Assets exclusifs à la feature
│   ├── image.png
│   └── ...
├── components/        # Composants UI spécifiques à la feature (ex: ParcoursCard.tsx)
├── hooks/             # Logique React locale (ex: useParcoursFilters.ts)
├── types/             # Interfaces TypeScript (ex: IParcours, IModule)
├── views/             # Les pages principales (ex: ParcoursHome.view.tsx, EditParcours.view.tsx)
└── routes.tsx         # Le sous-routeur de cette feature
```
